# Solar Africa Map

A comprehensive interactive map visualization project showcasing solar energy potential and infrastructure across African nations.

## 📋 Project Overview

This project provides an interactive map interface to explore solar energy resources, installations, and potential across Africa. It's designed to support research, education, and decision-making in the renewable energy sector.

## 🌍 Features

- **Interactive Map Interface** - Explore solar energy data across African regions
- **Regional Analysis** - View detailed information about solar potential by country
- **Data Visualization** - Visual representation of solar installations and infrastructure
- **Responsive Design** - Works on desktop and mobile devices

## 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/AlbertInnovates/solar-africa-map.git
cd solar-africa-map
```

2. Open `index.html` in your web browser or serve using a local server:
```bash
python -m http.server 8000
# or
npx http-server
```

3. Navigate to `http://localhost:8000` in your browser
